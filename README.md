# 梁清单检查与体积汇总工具

Python 入门作品：从文本文件读取梁资料，检查格式和尺寸，计算有效梁体积，并保存汇总报告。

## 运行环境

- Windows，已安装 Python 3。
- 无需安装第三方库。

## 项目文件

```text
beam-report-tool/
├── beam-report-tool.py
├── beam_data.txt
├── README.md
└── tests.md
```

成功运行后生成 `summary.txt`。

## 输入格式

输入文件为 `beam_data.txt`，使用 UTF-8 编码保存，不添加表头。

每行代表一根梁，顺序为：梁编号、长、宽、高。各项使用英文逗号分隔，长、宽、高的单位均为米。

示例：

```text
L-01,4,0.5,0.5
L-02,6,0.25,0.5
L-03,2,0.5,0.5
```

空行和只有空格的行会被跳过。

## 运行方法

将程序和输入文件放在同一个文件夹，在该文件夹中打开 PowerShell，运行：

```powershell
py .\beam-report-tool.py
```

窗口会显示逐行处理结果和汇总结果。使用上面的示例资料，生成的 `summary.txt` 内容为：

```text
无效梁数量：0
有效梁总体积：2.25立方米
```

报告保存在运行命令时所在的文件夹。按上述方法运行，报告与程序、输入文件位于同一文件夹。

## 检查与统计规则

- 每行必须恰好有 4 项。缺项或多项时，显示资料数量提示，该行计为一根无效梁。
- 长、宽、高必须能转换成数字。无法转换时，显示提示，该行计为一根无效梁。
- 三个尺寸都大于 0 时，计算体积：长 × 宽 × 高，单位为立方米。
- 任意尺寸小于或等于 0，该梁无效。即使多个尺寸不符合要求，也只计一根无效梁。
- 某行资料无效时，继续处理后面的资料。
- 只累计有效梁的体积。
- 空行不计入无效梁数量。

## 报告保存行为

- 输入文件正常读取并处理完成后，生成或覆盖 `summary.txt`。
- 输入文件不存在时，显示“找不到输入文件”，不重新保存报告；已有报告保留。
- 输入文件存在但为空时，正常保存报告，无效梁数量和有效梁总体积均为 0。
